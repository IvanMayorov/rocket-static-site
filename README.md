# ROCKET static Webflow export

This repository contains the static HTML export of the ROCKET website. CMS articles, cases, and news are rendered as ordinary HTML pages; no Webflow CMS connection is required.

GitHub Pages deploys automatically after each push to `main`. The workflow adjusts root-relative links for the repository's Pages URL before publishing.

The source export is about 306 MB and contains 2,498 files. Original Webflow ZIP and CMS CSV exports are kept outside this repository.
